## 1. 课程起点

课程为“海洋数据挖掘”。出发知识包括 Workflow 与 Agent 的区别、工具调用，以及“AI 智能体也是分布式系统”所涉及的状态、超时和重试问题。学生希望将课程知识连接到已有水下机械臂的感知、抓取、搬运、放置和释放任务，而不是抽象讨论通用聊天机器人。

## 3. 被明确采纳的质疑

**“异常恢复不是 Agent 专利。”** 因此不将“发生异常后能重试”作为贡献，A 组必须具备合理的证据检查和全部诊断工具。

**“证据矛盾不等于 Agent 有用。”** 因此先处理时效与对象关联，再评估可获取的新信息及相对收益。即使冲突严重，没有新证据来源也可能只能保持 UNKNOWN。

**“动态规则不等于新算法。”** 因此区分 D0 工程基线与 D1 收益学习，引用已有成本敏感求助思想，不宣称新的理论范式。

**“自主性不能替代安全授权。”** 因此两种高层策略共用安全审核，Agent 无权授权张爪或修改安全参数。

**“整体提升不能证明模块贡献。”** 因此用单因素消融、交叉实验及预测—决策—执行日志分析，而不是只展示成功视频。

**“永远停止也能零危险。”** 因此同时评价诊断覆盖率、正确率、任务完成和过度保守，不以单一安全分数排名。

## 4. 当前最终研究问题

在同一放置后 UNKNOWN 状态、相同传感器观测、相同工具与预算下，Agent 相对强规则 Workflow 是否存在可预测的正增量收益？利用状态证据和恢复历史进行成本敏感选择，是否能改善诊断效果—耗时—计算成本的权衡？
