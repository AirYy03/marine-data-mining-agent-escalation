## 讨论内容导航

讨论围绕“海洋数据挖掘”课程中的 Workflow、Agent、工具调用和分布式系统可靠性展开，依次涉及：

1. 将课程知识连接到水下机械臂抓取、搬运、放置任务。
2. 质疑“正常 Workflow、异常 Agent”是否只是已有架构重组。
3. 将研究收缩到“下降完成，但支撑状态尚未可靠确认”。
4. 文献调查与创新边界审视；承认强规则 Workflow 可能已足够。
5. 状态证据有效性、历史诊断及 Agent 增量收益—成本模型。
6. Agent 技能白名单、独立安全监督和释放权限分离。
7. A/B/C/D 对照、分级异常、真值隔离、随机种子和泛化测试。
8. 覆盖率、正确诊断、安全与成本指标，以及证据/历史/成本消融。
